# Soundarya Srikanta — Portfolio

Personal software engineering portfolio for https://soundarya2908.github.io.

## Structure
- `index.html`: professional experience, work stories, and contact links.
- `assets/css/portfolio.css`: responsive visual design and accessibility styles.
- `assets/js/portfolio.js`: mobile navigation and footer year.
- `assets/resume.pdf`: downloadable resume.

## Preview
Serve the repository root using a local static web server. No build or dependencies are required.

## Publish
Push the reviewed changes to the branch configured as the GitHub Pages source. The site is served from the repository root. The local `dist` directory and `.openai/hosting.json` are preview-only and are not committed.

## Content
Keep experience and performance figures grounded in the resume and verified professional accomplishments. Avoid sharing confidential implementation details. The website uses local assets and does not include analytics or third-party script dependencies.
